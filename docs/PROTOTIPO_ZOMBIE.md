# Zombie Survival: primer prototipo

Se añadieron scripts para movimiento provisional del personaje, cámara de seguimiento y joystick táctil dibujado por código. La herramienta de editor crea una escena nueva llamada `ZombiePrototype` y configura la orientación horizontal. Conserva `SampleScene` sin cambios.

Para crear la escena en Unity: espera a que termine de importar los scripts y usa el menú `BERNEOX > Crear escena de prototipo Zombie Survival`. En la escena, pulsa Play. En computadora se mueve con WASD/flechas; el joystick queda preparado para pantalla táctil.

La cámara elevada detrás del personaje es provisional para probar movimiento. Se puede cambiar cuando se confirme el ángulo final. Aún no hay enemigos, combate, interfaz final ni compilación Android.
